# ADR-0005：挂机可被杀，但死亡不夺装备

- 状态：已接受
- 日期：2026-11-28

## 背景

挂机模式必须带风险，否则「挂着」等于无风险印钞，玩家不会回来管。但惩罚过重（掉装备、掉等级）会让刷宝游戏最核心的资产受到威胁，玩家会直接弃坑。

## 决定

1. **死亡不丢装备、不降等级、不掉金币**。
2. 但死亡会**中断挂机**：人回到城中，不再刷怪，必须手动点「继续挂机」。
   这就是惩罚 —— 你回来发现自己的人物在城里发呆，进度停了两小时。
3. 血量低于 40% 自动服丹，丹有数量上限、靠金币买。装备太差硬撑高层时，药钱会烧光，经济压力自然把玩家推回低层。
4. 离线收益**只给经验、金币、强化矿，绝不给装备**，上限 8 小时。

## 理由

用「时间损失」替代「资产损失」，是刷宝游戏里唯一可持续的惩罚形式。玩家的装备是安全感的来源，动它等于劝退。

离线不给装备，是因为「刷」是本项目的全部乐趣。给装备等于让挂机替代游戏本身。

## 落地

`src/sim/world.ts` 的 `interrupted` 字段与 `resumeFarming()`；离线结算见 `computeOfflineReward`。
