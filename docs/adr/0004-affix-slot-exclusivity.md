# ADR-0004：词条严格部位专属

- 状态：已接受
- 日期：2026-11-28

## 背景

18 条词条、8 个部位。如果每条词条都可能出现在每个部位上，那么「这件装备出了什么」几乎是均匀随机的 —— 玩家无论刷到什么，都只是数值大小的区别，没有「我在凑一个流派」的感觉。

## 决定

**每条词条带一份部位白名单**，只能出现在白名单内的部位：

| 词条族 | 例子 | 允许部位 |
|---|---|---|
| 攻击 | 暴击率 | 手、武器、戒 |
| 攻击 | 攻速 | **只有手** |
| 攻击 | 破甲 | 武器、手 |
| 防御 | 闪避 | 鞋、腰 |
| 防御 | 减伤 | 衣、头 |
| 元素 | 灼烧/冰冻/中毒 | 武器、戒 |
| 武学 | 剑法/刀法等级 | 武器、戒（蓝装以上） |
| 武学 | 冷却缩减 | 头、腰 |
| 功能 | 掉落率/经验 | 戒、鞋 |
| 功能 | 吸血 | 手、武器 |

## 理由

部位专属是「随机系统有没有意义」的分水岭。攻速只出在手上，玩家就会去刷手；剑法等级只出在武器和戒指上，玩家就会为了这两件反复刷同一层。**约束制造了目标**，无约束的均匀随机只制造噪音。

## 同时砍掉的东西

- 所有**百分比攻击**词条：一条就能把其余 17 条变成摆设，是数值膨胀的根源。
- 除雷击之外的第四个元素：三种元素（灼烧/冰冻/中毒）的伤害节奏已经够区分玩法。
- 除吸血外的所有回复词条。

## 测试

`src/sim/loot.test.ts` 用 300 次随机生成逐条校验「词条不会出现在不允许的部位」，并单独校验攻速只出在手、剑法等级只出在武器与戒指。
