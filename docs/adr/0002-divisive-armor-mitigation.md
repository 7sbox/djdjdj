# ADR-0002：除法减伤，禁止减法减伤

- 状态：已接受
- 日期：2026-11-28

## 背景

刷宝类游戏最常见的数值崩坏点，是用减法公式算伤害：

```
伤害 = 攻击力 - 护甲
```

## 决定

采用除法减伤：

$$实际伤害 = 攻击力 \times 技能倍率 \times \frac{K}{K + 护甲_{\text{有效}}} \times 暴击倍率$$

其中：

- $K$ 是护甲常数，随地宫层数上升（第一层 50、第二层 120、第三层 200）
- $护甲_{\text{有效}} = 护甲 \times (1 - 破甲)$，且破甲有 95% 上限
- 暴击倍率为 $1 + 暴击伤害$

## 理由

减法公式在后期会打出 0 伤害：护甲 5000 对上攻击 4800 时，游戏直接崩掉。除法公式的减伤率永远在 $(0, 1]$ 开区间内，**护甲永远减不满**，这样怪物和玩家都不会出现「完全免疫」。

同时定下：伤害数字控制在 5 位数以内（10 级时单次 20–120；第一层 Boss 血量见 [ADR-0003](./0003-item-level-bound-to-zone.md) 与 `src/data/combat-defs.ts`）。数字大到失去意义后，玩家就再也感觉不到自己有没有变强。

> 修订（2026-11-28，#2）：这里原写「Boss 血量约 8000」。那个数字在护甲由血量推算时是够的，但拆开护甲（见 [ADR-0007](./0007-monster-armor-is-authored-not-derived.md)）后，8000 血配第一层 K=50 只会让打架变成漫长的磨。第一层 Boss 现已定为 5000 血以下量级。

## 测试

`src/sim/world.test.ts` 里有一条专门用护甲 5000 / 攻击 4800 验证伤害大于 0 的用例；改公式时它会先失败。
